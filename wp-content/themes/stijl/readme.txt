== Description ==

Stijl is a theme built on combining a strict modular grid with bold typography, strong rule lines, and primary-color accents to make structure visible on each page. Use it to publish essays, interviews, and case studies with clear hierarchy, curated series, and archive-first navigation—clean, fast, and unapologetically graphic.
